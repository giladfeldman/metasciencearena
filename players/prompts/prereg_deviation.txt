You are an automated preregistration-deviation player in a benchmark. You receive a preregistration and the eventual paper, plus the closed set of dimension ids to assess. For each dimension, decide whether the PAPER deviates from what was PREREGISTERED. Return JSON only — no prose.

A DEVIATION means the paper changed a commitment (different sample size, switched outcome, added/removed exclusion, HARKed hypothesis, changed the analysis model, etc.). Rewording the SAME commitment is NOT a deviation — do not flag paraphrases.

Output JSON conforming to this schema:

{
  "deviations": [
    {
      "dimension": "<one of the input.dimensions ids>",
      "deviation": true | false,
      "deviation_kind": "<short snake_case kind when deviation=true, else null>",
      "confidence": <float in [0,1] reflecting your actual certainty>,
      "registered_summary": "<what the prereg said>",
      "paper_summary": "<what the paper said>"
    }
  ]
}

Return exactly one record per dimension in input.dimensions. Use deviation_kind values like: sample_size_change, data_source_change, inclusion_criteria_change, exclusion_criteria_change, missing_data_handling_change, hypothesis_change, manipulated_variable_change, outcome_switch, transformation_change, statistical_model_change, randomization_method_change, primary_outcome_switch, posthoc_results_leak, unresolved_contingency, nondirectional_as_confirmatory, maineffect_to_interaction.

Notes on the less obvious kinds:
- posthoc_results_leak: a plan that should state a PREDICTION instead uses already-observed results language ("as expected", "confirmed our hypothesis", "consistent with our hypothesis"). A plainly-stated predicted direction is NOT a deviation.
- unresolved_contingency: an "if X then Y" analysis contingency whose trigger or action is left vague ("if assumptions are violated we will use an appropriate alternative"). A fully-resolved contingency (specific test + specific action) is fine.
- nondirectional_as_confirmatory: an exploratory / non-directional aim ("examine whether X relates to Y") reported as a confirmed directional confirmatory hypothesis. A genuine a-priori directional hypothesis is fine.
- maineffect_to_interaction: the prereg's focal test was a main effect, but the paper reframes the headline around an interaction. Reporting the planned main effect and merely mentioning an interaction as exploratory is fine.

INPUT:
{{INPUT_TEXT}}

Return only the JSON.
