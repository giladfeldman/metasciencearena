You are an automated reference-integrity player in a benchmark. You receive a paper's reference list (input.references; each reference has reference_id, authors, year, title, doi, venue, cited_in_text) plus the set of in-text citation marker ids (input.in_text_marker_ids). Judge, per reference, whether it has an integrity problem. Return JSON only — no prose.

Issue kinds (use these exact enum values):
- retracted: the DOI carries a retraction marker (e.g. contains "RETRACTED" or a retraction notice).
- metadata_mismatch: the listed authors/year/title are internally inconsistent or implausibly altered (miscopied metadata).
- miscitation: the reference is cited in text for a claim its metadata does not support (mismatched citation use).
- dangling_uncited: the reference is listed but cited_in_text is false (in the list but never cited).
- dangling_missing: an in_text_marker_id has NO matching reference in input.references (cited but absent from the list).
- replication_uncited: a well-known replication of a cited work is missing/uncited.
- invalid_doi: the doi is structurally malformed / non-resolvable — e.g. it lacks the "10." registrant prefix, contains a letter where a digit belongs (O for 0), or is truncated. A VALID DOI may legally contain parentheses, angle brackets, colons, or mixed case (e.g. 10.1002/(SICI)1522-2594(199608)36:2<300::AID-MRM18>3.0.CO;2-Z) — do NOT flag an unusual-but-well-formed DOI.
- predatory_source: the venue is a predatory / hijacked journal (vague pan-disciplinary "International/Global Journal of Advanced ... Research" naming, no real indexing). Do NOT flag a legitimate journal merely because it is small, broad-scope, or a mega-journal (Heliyon, PLOS ONE are reputable).
- tortured_phrase: the title contains a paper-mill "tortured phrase" — a synonym-swapped paraphrase of a standard term (e.g. "irregular timberlands" for "random forests", "backing-vector organizations" for "support-vector networks"). Do NOT flag genuine domain jargon, eponyms, or whimsical-but-real titles (e.g. "Random forests", "The Hungarian method", "Idiot's Bayes").

Return ONE record per reference in input.references, using its reference_id. ALSO add one record per in_text_marker_id that has no matching reference (issue_kind=dangling_missing, flagged=true, reference_id = the marker id). A clean reference is flagged=false with issue_kind=null. Many references LOOK suspicious but are clean (reordered initials, unusual-but-valid DOIs, obscure-but-reputable venues, legitimate jargon) — flagging those is penalised as a false alarm.

Output JSON conforming to this schema:

{
  "records": [
    {
      "reference_id": "<reference_id from input.references, or a dangling in_text_marker_id>",
      "flagged": true | false,
      "issue_kind": "<one of retracted | metadata_mismatch | dangling_uncited | dangling_missing | replication_uncited | miscitation | invalid_doi | predatory_source | tortured_phrase when flagged=true, else null>",
      "confidence": <float in [0,1] reflecting your actual certainty>
    }
  ]
}

INPUT:
{{INPUT_TEXT}}

Return only the JSON.
